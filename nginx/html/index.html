03 / DELIVERY PIPELINE

From Git push to Kubernetes

The application follows a GitOps-based deployment flow.

01

Git Push

Application changes are committed and pushed to GitHub.

02

GitHub Actions

The CI pipeline builds and publishes a new Docker image.

03

Docker Hub

The container image is stored in the container registry.

04

Argo CD

Argo CD detects the desired state defined in the GitOps repository.

05

K3s

Kubernetes pulls the image and runs the new application version.

04 / ABOUT THE LAB

Built to learn by doing.

This laboratory is a hands-on environment for learning DevOps engineering.

The goal is not simply to deploy an application, but to understand what happens at every stage: from a Git commit to a running workload inside Kubernetes.
